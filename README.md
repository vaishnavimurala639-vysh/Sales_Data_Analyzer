# Sales Data Analyzer

## About the Project
Sales Data Analyzer is a Python-based data analytics project used to analyze sales data and generate useful business insights.

## Technologies Used
- Python
- Pandas

## Features
- Total sales calculation
- Product-wise sales analysis
- City-wise sales analysis
- Category-wise sales analysis
- Best-selling product identification
- Best-performing city identification
- Best category identification

## Project Output
The project analyzes sales data and displays important sales insights in the terminal.

## How to Run
1. Install Python.
2. Install Pandas:
   `pip install pandas`
3. Run the Python file:
   `python sales_analysis.py`
